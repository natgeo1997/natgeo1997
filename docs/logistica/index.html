01 — INTELIGÊNCIA OPERACIONAL

LogiOps AI

Protótipo independente · Público

Python / Streamlit / Gemini / Pydantic

Um relato de ocorrência pode reunir informações dispersas. O LogiOps AI organiza esse relato em uma avaliação inicial estruturada para revisão por um profissional de logística.

  • Entrega: sugestão de prioridade, impacto e possíveis causas a verificar.
  • Ações recomendadas e preventivas, com rascunho de comunicação.
  • Exportação em JSON e TXT; validação da estrutura dos dados.

02 — GOVERNANÇA DOCUMENTAL

DocManager

Protótipo independente · Público

React / JavaScript / Python / FastAPI / OpenAI API

Revisar documentos exige identificar mudanças e manter o responsável no controle. O DocManager explora edição, comparação de versões e histórico de alterações assistido por IA.

  • Entrega: comparação visual de trechos adicionados e removidos.
  • Sugestão de histórico editável antes da inclusão pelo revisor.
  • Rascunhos locais, testes e avaliação com limitações documentadas.
Explorar repositório ↗Funcionamento e limites ↗

A publicação no protótipo é simulada. Não é um sistema corporativo de controle documental; não há ganhos de produtividade em produção comprovados.
