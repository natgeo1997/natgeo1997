01 / ANÁLISE DE FICHAS DE SEGURANÇA

SDS Analyzer Bot

Projeto corporativo · Interno

Python / GCP: Cloud Functions e Cloud Scheduler / OpenAI API / pdfplumber

Desenvolvi o SDS Analyzer Bot para automatizar a leitura de fichas de segurança (SDS/FISPQ) recebidas por e-mail. O robô extrai o texto dos PDFs, faz uma análise inicial com IA e envia a resposta à operação.

  • Leitura dos PDFs em Python, com extração de texto pelo pdfplumber.
  • Análise do conteúdo pela OpenAI API.
  • Execução no Google Cloud Functions, agendada pelo Cloud Scheduler.
  • Recebimento de anexos e envio de respostas por e-mail.
02 / OCORRÊNCIAS LOGÍSTICAS

LogiOps AI

Protótipo independente · Público

Python / Streamlit / Gemini / Pydantic

O LogiOps AI recebe o relato de uma ocorrência logística e organiza uma análise inicial. Sugere a prioridade, aponta possíveis causas e reúne ações que o profissional pode avaliar antes de dar andamento ao caso.

  • Sugestões de prioridade, impacto operacional e possíveis causas.
  • Ações recomendadas e preventivas, além de um rascunho de mensagem.
  • Dados validados com Pydantic e exportação em JSON e TXT.

03 / REVISÃO DE DOCUMENTOS

DocManager

Protótipo independente · Público

React / JavaScript / Python / FastAPI / OpenAI API

O DocManager permite editar documentos e comparar versões para ver o que mudou. A IA sugere um texto para o histórico de alterações, que pode ser revisado e ajustado antes de ser incluído.

  • Comparação visual dos trechos adicionados e removidos.
  • Sugestão de histórico de alterações com edição pelo revisor.
  • Rascunhos salvos no navegador, testes e avaliação descritos no repositório.
